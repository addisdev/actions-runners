# Fleet Cockpit

The macOS menu bar client for the fleet dashboard. Documentation:
[docs/cockpit.md](../docs/cockpit.md).

```
Package.swift            CockpitCore (models, transport, SSE, store, presenter) + the `cockpit` CLI
Sources/CockpitCore/     everything testable; Fixtures/ is generated by dashboard/scripts/make-glance-fixtures.mjs
Tests/CockpitCoreTests/  swift test — no Xcode project, no simulator
App/                     the SwiftUI menu bar app; `xcodegen generate` makes the project
```
