# Support

## Bugs and feature requests

Open a [GitHub Issue](https://github.com/addisdev/actions-runners/issues) using
the appropriate template. Please search existing issues before opening a new one.

## Security vulnerabilities

Do **not** open a public issue for security vulnerabilities. Use GitHub's
[private vulnerability reporting](https://github.com/addisdev/actions-runners/security/advisories/new)
instead. See [SECURITY.md](SECURITY.md) for the full policy.

## Troubleshooting

The [Troubleshooting guide](docs/troubleshooting.md) covers the most common
failure modes: offline runners, stuck queues, label mismatches, load/swap
pressure, auth issues, and migration errors.

## Questions

For general usage questions, open a [GitHub Discussion](
https://github.com/addisdev/actions-runners/discussions) if the project has
Discussions enabled, or an issue tagged `question`.

## Scope

This project is deliberately small tooling for one macOS host. Before opening
an issue, please check [CONTRIBUTING.md](CONTRIBUTING.md) for what fits in
scope and what does not.

## Response expectations

This is a small open-source project maintained by one person. Response times
are best-effort; security issues receive priority.
